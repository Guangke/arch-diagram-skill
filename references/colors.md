# 语义配色方案 / Semantic Color System

> 原则：**颜色表达语义，不表达心情**。看图的人应该能靠颜色直接读出组件类别。色值为 Tailwind 调色板中的通用色值。

## 1. 组件语义色板（亮色主题 · 默认）

采用"浅色底 + 深色描边 + 深色文字"的 tinted 风格：柔和、易读、好扩展。

| 语义 | 代表组件 | 填充 fill | 描边 stroke | 文字 |
|---|---|---|---|---|
| 计算 Compute | API、微服务、函数 | `#DBEAFE` | `#2563EB` | `#1E293B` |
| 数据 Data | 数据库、缓存、数据湖 | `#DCFCE7` | `#16A34A` | `#1E293B` |
| 外部 External | 第三方 API、SaaS、客户系统 | `#FFEDD5` | `#EA580C` | `#1E293B` |
| 基础设施 Infra | 网络、网关、负载均衡、消息队列 | `#F3F4F6` | `#4B5563` | `#1E293B` |
| 安全 Security | 鉴权、防火墙、加密、WAF | `#FEE2E2` | `#DC2626` | `#1E293B` |
| 可观测 Observability | 日志、监控、告警、链路追踪 | `#EDE9FE` | `#7C3AED` | `#1E293B` |

### 备选：填充式（白字）

演示 / 海报场景可用实底白字，对比更强烈：

| 语义 | 填充 | 文字 |
|---|---|---|
| 计算 | `#2563EB` | `#FFFFFF` |
| 数据 | `#16A34A` | `#FFFFFF` |
| 外部 | `#EA580C` | `#FFFFFF` |
| 基础设施 | `#4B5563` | `#FFFFFF` |
| 安全 | `#DC2626` | `#FFFFFF` |
| 可观测 | `#7C3AED` | `#FFFFFF` |

一张图内二选一，不要混用两种风格。

## 2. 画布与结构色

| 元素 | 值 |
|---|---|
| 画布背景 | `#FFFFFF` |
| 层带 / 组框填充 | `#F8FAFC` |
| 层带 / 组框描边（dashed） | `#CBD5E1` |
| 层带标签、注释文字 | `#64748B` |
| 正文主色 | `#1E293B` |
| 次要文字 | `#64748B` |

## 3. 连线与线型

| 元素 | 值 / 写法 |
|---|---|
| 连线颜色 | `#64748B`（灰蓝中性，不抢语义色） |
| 同步 / 强依赖 | 实线，`stroke-width: 1.8` |
| 异步 / 事件 / 返回 | 虚线 `stroke-dasharray: 6 4` |
| 控制流 / 配置下发 | 点线 `stroke-dasharray: 2 4` |
| 主链路强调 | 提升到 `stroke-width: 2.6`，颜色不变 |
| 箭头 | 实心 `#475569`；返回线用空心 |

## 4. 状态色（组件健康度标注）

| 状态 | 色值 | 用法 |
|---|---|---|
| 正常 | `#16A34A` | 左上角状态点或细描边 |
| 降级 / 警告 | `#D97706` | 同上 |
| 故障 | `#DC2626` | 同上，可加浅红底 `#FEE2E2` |
| 未知 / 初始化 | `#94A3B8` | 同上 |

状态用"点 + 描边"表达，不要整体换填充色，避免与语义色混淆。

## 5. 暗色主题（可选变体）

| 语义 | 填充 | 描边 | 文字 |
|---|---|---|---|
| 计算 | `#1E3A8A` | `#60A5FA` | `#EFF6FF` |
| 数据 | `#14532D` | `#4ADE80` | `#F0FDF4` |
| 外部 | `#7C2D12` | `#FB923C` | `#FFF7ED` |
| 基础设施 | `#1F2937` | `#9CA3AF` | `#F3F4F6` |
| 安全 | `#7F1D1D` | `#F87171` | `#FEF2F2` |
| 可观测 | `#4C1D95` | `#A78BFA` | `#F5F3FF` |
| 画布 / 层带 | `#0F172A` / `#1E293B` | 边 `#334155` | 标签 `#94A3B8` |
| 连线 | `#94A3B8` | — | 标签 `#CBD5E1` |

用户明确要暗色主题时整体替换，不要只换一半。

## 6. 用色纪律

1. 一张图主色（色相）≤6 种，恰好对应六个语义；不够用时优先用灰阶与形状区分，不是加色相
2. 灰阶留给基础设施与结构元素（层带、连线、注释）
3. 同一语义全图只用一个色值，不接受"深蓝浅蓝都是计算"
4. 文字对比度：tinted 风格用深灰字 `#1E293B`，填充式用白字；不确定时按 WCAG AA（≥4.5:1）估
5. 打印 / 黑白场景：确认去掉颜色后仍能靠形状与标签区分组件（描边样式差异化）
